# Ciao-Italiano
yo quiero hacer una pagina para aprender italiano, cada persona tendra su perfil y se guardara el proceso de sus leccioes. comenzaremos con temas como pronombres, luego colores, dias de la semana, meses del año, frutas, verduras, desayunos, objetos, partes del cuerpo, prendas, objetos de viajes, etc.
